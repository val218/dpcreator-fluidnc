      Script help

      G-code and $ commands, one per line. FluidNC also has:
  #<depth> = 2.5            named variable (#<_name> = kept between macros)
  G1 Z[0 - #<depth>] F300   maths in [ ]
  o100 if [#<depth> GT 3]   ... o100 elseif [...] ... o100 else ... o100 endif
  o101 while [#<n> LT 5]    ... o101 endwhile     (also do/while, repeat [n])
  (PRINT, depth %.2f mm, #<depth>)   message to the terminals
  #5061 #5062 #5063  last probe position (machine)   #5070 = 1 if it touched
  #<_x> #<_y> #<_z>  current work position
  G38.2 Z-20 F100            probe down until it touches (error if not)
