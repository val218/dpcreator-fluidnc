Board tools

USB terminal, files and network

FreeAny FluidNC board

Talk to the controller over USB: send commands and read its log, open and edit config.yaml, copy files to and from the board's flash and SD card, and set up its WiFi or Ethernet. Nothing to install; use Chrome or Edge on a computer.

The board tools need Chrome or Edge on a computer (Web Serial). They don't work on phones, tablets, Firefox or Safari.


    

      Board requirements. This firmware needs an ESP32‑S3 with 8 MB octal PSRAM: an ESP32‑S3‑WROOM‑1 N8R8, N16R8 or N32R8V module (the part number on the module's metal shield ends in R8). Modules with 2 MB PSRAM (N8R2, N16R2) or none (N4, N8, N16) are not supported: they run out of memory during jobs and restart. Classic ESP32 boards (ESP32‑WROOM‑32) are not supported by this firmware. Connect a board and the tools above tell you what it has.
