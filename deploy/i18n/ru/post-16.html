После свежей установки прошивки плата уже стартует с включённым Ethernet и DHCP: подключите кабель и найдите IP-адрес. Эта страница пригодится, чтобы перейти на постоянный IP или вернуться с Wi-Fi.

1. В config.yaml должен быть раздел Ethernet

spi:
  miso_pin: gpio.13
  mosi_pin: gpio.11
  sck_pin: gpio.12

ethernet:
  cs_pin: gpio.14
  int_pin: gpio.9        # NO_PIN if INT is not wired
  rst_pin: NO_PIN
  phy_type: w5500
  phy_addr: 1
  frequency_hz: 8000000  # safe on a bus shared with the SD card

Важно: если int_pin задан, но INT на самом деле не подключён, связь поднимается, но пакеты не приходят (DHCP не срабатывает, ping не проходит). В этом случае укажите int_pin: NO_PIN.

Без раздела ethernet: плата переключается на Wi-Fi, чтобы оставаться доступной, — в вашу сохранённую сеть или в собственную точку доступа FluidNC по адресу http://192.168.0.1.

2. Выберите DHCP или постоянный IP

Отправьте эти команды через USB (последовательную консоль), по одной строке.

Автоматически (DHCP):

$network/type=Ethernet
$Ethernet/IPMode=DHCP
$bye

Постоянный IP (рекомендуется — возьмите свободный адрес в своей сети):

$network/type=Ethernet
$Ethernet/IPMode=Static
$Ethernet/IP=192.168.10.50
$Ethernet/Netmask=255.255.255.0
$Ethernet/Gateway=192.168.10.1
$bye

После этого Wi-Fi выключен. Чтобы вернуться: $network/type=WiFi, затем $bye через USB.

3. Проверьте

После перезагрузки $Ethernet/Status или $Startup/Show должны показать Ethernet link up и Ethernet IP is …. Затем выполните ping этого IP с ПК и откройте http://<ip> или http://fluidnc.local.

4. gSender по Ethernet

  1. В gSender откройте Config → Ethernet.
  2. Введите IP-адрес платы и порт 23 (или ваш $Telnet/Port), нажмите Apply Settings.
  3. В меню подключения выберите пункт Ethernet, а не COM-порт.

Не используйте Remote Mode в gSender — он предназначен для адреса самого ПК и выдаёт «Remote mode has been disabled».

Полезные команды

$Ethernet/StatusСвязь, IP, маска, шлюз, MAC
$Ethernet/InitЗапустить W5500 вручную (для проверки)
$network/typeWiFi или Ethernet
$Telnet/PortПорт, к которому подключается gSender (по умолчанию 23)
