Плата открывает доступ к своей SD-карте в вашей сети по адресу http://<board-ip>/sd. Подключите её один раз и копируйте на неё G-код, как на флешку. Превью для пульта (.viz) строятся автоматически для каждого скопированного файла G-кода.

Windows: простой способ

  1. В панели Files в WebUI нажмите PC drive. Скачается скрипт установки, в котором уже указан IP-адрес вашей платы.
  2. Запустите его двойным щелчком (не используйте «Запуск от имени администратора»). Если Windows выдаст предупреждение, нажмите Подробнее → Выполнить в любом случае.
  3. Ответьте Да на единственный запрос прав администратора. SD-карта появится как диск S: с именем dpCREATOR SD и будет переподключаться при каждом входе в систему.

Если IP-адрес платы изменится, запустите скрипт ещё раз. Чтобы всё удалить: dpcreator-sd-drive.cmd remove.

macOS и Linux

  • macOS: Finder → Переход → Подключение к серверу → http://<board-ip>/sd
  • Linux: файловый менеджер с адресом dav://<board-ip>/sd или davfs2

Советы

  • Дайте плате постоянный IP-адрес, чтобы диск продолжал работать после перезагрузки.
  • Если ввести \\<board-ip> в Проводнике, будет ошибка — у платы нет общего доступа к файлам Windows (SMB). Используйте диск S:.
  • Не копируйте большие файлы, пока с SD-карты выполняется задание; у задания приоритет.
  • Оставляйте файлы .viz рядом с G-кодом — их использует пульт.
