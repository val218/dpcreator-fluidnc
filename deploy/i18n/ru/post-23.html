Страница Flash Firmware устанавливает самую новую сборку прямо из браузера. Она всегда предлагает последнюю версию, автоматически собранную из исходников.

Что понадобится

  • Chrome или Edge на настольном компьютере. Firefox и Safari не поддерживают Web Serial.
  • USB-кабель для передачи данных. Кабели только для зарядки не видны как порт.

Шаги

  1. Контроллер: сохраните резервную копию конфигурации. Сначала скачайте config.yaml из файлового менеджера WebUI. Полный образ заменит его примером конфигурации dpCREATOR. (Пульт свои настройки сохраняет.)
  2. Войдите в свою учётную запись на dpcreator.eu. Подключите плату, которую нужно прошить, — контроллер или пульт, по одной. Для пульта сначала отсоедините кабель контроллера.
  3. Откройте Flash Firmware и выберите вкладку Controller или Pendant.
  4. Контроллер: нажмите Flash via browser, затем Connect & flash firmware, выберите последовательный порт и нажмите Install. Дождитесь Installation complete, перезапустите плату, снова загрузите свой config.yaml и перезагрузите командой $bye. Если вы пользуетесь dpCREATOR WebUI, установите его заново со вкладки WebUI: полный образ возвращает стандартную страницу FluidNC, а повторная установка не расходует плату из лицензии.
  5. Пульт: нажмите Connect and install и выберите последовательный порт. Страница прочитает ID чипа пульта, при первой установке зарегистрирует его в вашей лицензии и установит последнюю версию SmartTabUI с лицензией. Когда появится Done, пульт перезапустится сам. См. Установка, обновление и регистрация SmartTabUI.
  6. Не отключайте плату во время прошивки.

Какая сборка для чего

ПлатаЧипОбраз
Контроллер dpCREATOR R2/R3ESP32-S3FluidNC 4.1.1 + W5500, полный образ по адресу 0x0 (загрузчик, прошивка и стандартная страница FluidNC). dpCREATOR WebUI устанавливается отдельно.
Пульт SmartTabUIESP32Прошивка SmartTabUI по адресу 0x0, лицензия по адресу 0x310000 (настройки сохраняются)
