Контроллер управляет шпинделем двумя способами: PWM + реле (по умолчанию в примере конфигурации) или частотник по RS485 (Modbus). Используйте в config.yaml один из них.

PWM + реле (по умолчанию)

PWM:
  pwm_hz: 5000
  output_pin: gpio.21
  enable_pin: gpio.39     # relay: spindle on/off
  direction_pin: NO_PIN
  spinup_ms: 2000
  spindown_ms: 2000
  speed_map: 0=0.000% 24000=100.000%

Укажите в speed_map максимальные обороты своего шпинделя.

Частотник по RS485

RS485 работает на UART2 (TX GPIO42, RX GPIO41, driver enable GPIO40). Подключите A/B к клеммам RS485 частотника и настройте в самом частотнике управление по Modbus на 9600 бод, адрес 1. Затем замените раздел PWM: на свой тип частотника, например Huanyang:

uart2:
  txd_pin: gpio.42
  rxd_pin: gpio.41
  rts_pin: gpio.40
  baud: 9600
  mode: 8N1

Huanyang:
  uart_num: 2
  modbus_id: 1
  tool_num: 1
  spinup_ms: 5000
  spindown_ms: 5000
  speed_map: 0=0% 24000=100%

Типы частотников, которые поддерживает эта прошивка, — используйте имя как заголовок раздела вместо Huanyang::

Huanyang · YL620 · H2A · H100 · NowForever · SiemensV20 · DeltaMS300 · FolinnBD600 · MollomG70 · DanfossVLT2800 · ModbusVFD (универсальный, регистры задаёте сами)

Другие типы шпинделей: PWM, 10V, Relay, OnOff, Laser, BESC, DAC, HBridge, PlasmaSpindle. Для каждого частотника нужно также настроить его собственные параметры для управления по RS485 (скорость, адрес, источник пуска и частоты) — см. руководство к частотнику и вики FluidNC.

Безопасность: настраивайте и проверяйте частотник со шпинделем без нагрузки и без установленного инструмента.
