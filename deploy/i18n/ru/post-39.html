Выберите плату, конфигурацию, отметьте приложения и введите данные сети — остальное страница сделает сама по USB: прошивка, конфигурация, приложения, Wi-Fi и вход. Выбирайте из 21 платы: dpCREATOR R3 и R2, Doberman и платы FluidNC других производителей, такие как 6-Pack, Jackpot, MKS DLC32 и TinyBee, OpenBuilds BlackBox X32 и FYSETC E4. От платы зависит, какая прошивка будет записана. Платы на ESP32-S3 получают ту же сборку, что и R3. Платы на классическом ESP32 (WROOM-32) получают сборку для этого чипа: Wi-Fi вместо Ethernet, а функции, которым нужна дополнительная память S3, работают в облегчённых версиях.

Готовая конфигурация

Для большинства плат есть готовые файлы config.yaml из коллекции конфигураций сообщества FluidNC (GPL-3.0). Каждый файл проверяется по собственному списку настроек прошивки до того, как что-либо будет записано, и сначала его можно изменить в редакторе. Можно также оставить конфигурацию, которая уже есть на плате, выбрать свой файл или ответить на несколько вопросов и получить конфигурацию, собранную под ваш станок.

Конфигурации сообщества присылают пользователи, и dpCREATOR их не тестирует. Сверьте выводы и настройки со своей платой, прежде чем запускать станок.

Приложения за один раз

Отметьте приложения перед прошивкой, и они установятся сразу после конфигурации:

  • dpCREATOR WebUI: управление станком из любого браузера. Бесплатно с dpCREATOR R3 (отдельно или в комплекте); €19.99 для других плат.
  • WebUI Lite (новинка): для плат на WROOM-32 — тот же WebUI, в котором отключены функции, непосильные для этого чипа. Бесплатно при наличии учётной записи, работает со Studio Basic.
  • dpCREATOR Studio: проектирование и создание G-кода в браузере. Studio Basic бесплатна.
  • dpCREATOR Motion: соберите и автоматизируйте свой станок. Бесплатно с R3, €39 для других плат.

Приложения, на которые у вас есть лицензия, можно отметить; остальные показаны серым со ссылкой, где их получить. На платах WROOM-32 Studio и Motion устанавливаются на SD-карту, поэтому сначала вставьте в плату карту FAT32.

В вашей сети с самого начала

У только что прошитой платы нет точки доступа и нет пароля, поэтому достучаться до неё можно только по USB. На шаге Network and login выберите Ethernet-кабель (R3) или Wi-Fi, дайте плате имя и задайте пароль для входа. После прошивки страница отправит их по USB, перезапустит плату и покажет её адрес, например http://192.168.1.57/ или http://plasma.local/. Пароли отправляются только на плату; страница их не хранит.

Плата уже прошита? На том же шаге есть ссылка, чтобы задать сеть и вход по USB без повторной прошивки.

Пульт на платах WROOM-32

Пульт SmartTabUI работает и с контроллерами на WROOM-32: выберите это в настройках пульта.

Новое в бете: dpCREATOR PnP

Приложение для установки компонентов (pick-and-place) на станках FluidNC: верхняя камера находит реперные знаки платы и компоненты в лентах, нижняя камера проверяет каждый компонент на сопле, а вакуумное сопло устанавливает их. Это бета-версия: сообщайте нам о любой проблеме, и она будет исправлена как можно скорее. Прочитайте перед началом; участники клуба R&D пробуют первыми. В полном WebUI уже есть камера на голове с перекрестием для точек маршрута и измерений.
