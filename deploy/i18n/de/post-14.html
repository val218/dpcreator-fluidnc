Führen Sie diese Schritte einmal bei einem neuen Board aus. Boards aus dem Shop sind bereits geflasht — beginnen Sie bei Schritt 2.

  1. Neueste Firmware flashen (nur bei leerem Board oder großem Update): Seite Flash Firmware → Controller → Flash latest via browser. Verwenden Sie Chrome oder Edge.
  2. Netzwerk verbinden. Stecken Sie ein Ethernet-Kabel in das Board. Eine Neuinstallation startet mit Ethernet und aktivem DHCP. Die IP finden Sie in Ihrem Router oder über USB mit $Ethernet/Status.
  3. WebUI öffnen unter http://fluidnc.local oder http://<board-ip>.
  4. Maschine in config.yaml einrichten. Die Firmware startet mit der Beispielkonfiguration für dpCREATOR R2/R3. Stellen Sie mindestens steps_per_mm, max_travel_mm und die Referenzfahrt-Richtung für jede Achse sowie Ihre Spindel ein. Bearbeiten Sie die Datei im Dateimanager der WebUI und starten Sie dann mit $bye neu.
  5. Handbediengerät anschließen (optional). Die Kopfzeile der WebUI zeigt ein Pendant-Symbol, wenn es verbunden ist.
  6. Bewegung sorgfältig prüfen. Verfahren Sie jede Achse ein kurzes Stück und prüfen Sie die Richtung. Lösen Sie jeden Endschalter von Hand aus, bevor Sie eine Referenzfahrt machen.
  7. Referenzfahrt mit $H oder der Home-Taste, dann den Werkstück-Nullpunkt setzen.

Tipp: Geben Sie dem Board eine feste IP (statisch oder als DHCP-Reservierung im Router). Das Netzlaufwerk und gSender brauchen eine Adresse, die sich nicht ändert.
