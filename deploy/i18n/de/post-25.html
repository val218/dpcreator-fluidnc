Flashen

ProblemLösung
Kein serieller Port zur AuswahlVerwenden Sie Chrome oder Edge, ein USB-Datenkabel und einen anderen USB-Port. Schließen Sie alle anderen Programme, die den Port nutzen (gSender, serieller Monitor).
„Device not supported“ / keine VerbindungHalten Sie beim Einstecken des USB-Kabels die Taste BOOT gedrückt, um in den Bootloader-Modus zu gelangen, und versuchen Sie es erneut. Prüfen Sie, ob Sie den richtigen Reiter gewählt haben (Controller oder Handbediengerät).
Browser stuft den Download als gefährlich einFehlalarm bei einer unbekannten Datei. Wählen Sie Behalten / Trotzdem herunterladen.

Netzwerk

ProblemLösung
Ethernet PHY init failedAbschnitt spi: oder ethernet: fehlt, falsche Pins oder Verdrahtung.
Link aktiv, aber IP 0.0.0.0, Ping schlägt fehlINT konfiguriert, aber nicht verdrahtet: int_pin: NO_PIN setzen. Oder kein DHCP-Server in diesem Netzwerk.
Statische IP: „Destination host unreachable“Board und PC sind in verschiedenen Subnetzen. Verwenden Sie eine Adresse im Subnetz Ihres PCs.
gSender: „Remote mode has been disabled“Verwenden Sie Config → Ethernet, nicht Remote Mode.
gSender: keine Verbindung möglichIP/Port in Config → Ethernet müssen zum Board passen ($Telnet/Port, Standard 23). Klicken Sie auf Apply Settings.
Board im WLAN-Access-Point „FluidNC“config.yaml hat keinen Abschnitt ethernet:, oder das Board ist 3-mal hintereinander abgestürzt. Öffnen Sie http://192.168.0.1 und laden Sie die richtige Konfiguration hoch.

Handbediengerät

ProblemLösung
$Pendant/Status meldet noneKein Abschnitt uart_channel1 in config.yaml.
Kein oder falscher Werkzeugweg am HandbediengerätPrüfen Sie die Konsole der WebUI auf VizErr; neu erstellen mit der Taste .viz an der Datei.
RX overflow / verstümmelte Meldungen im Terminal des HandbediengerätsBytes gehen auf dem Kabel verloren: Verwenden Sie ein kürzeres oder geschirmtes Kabel oder eine niedrigere Baudrate (auf beiden Seiten gleich). $Pendant/Debug zeigt die Zähler.
Keine Job-Wiederaufnahme am HandbediengerätDie Controller-Firmware ist älter als die des Handbediengeräts. Flashen Sie beide.

Abstürze

Wenn die WebUI Controller restarted after a crash anzeigt, klicken Sie auf Copy details und senden Sie uns den Text über das Kontaktformular.

Ein Problem ist vielleicht schon in einem neueren Build behoben: Sehen Sie in die Versionshinweise und Fehlerbehebungen und aktualisieren Sie dann über die Seite Flash Firmware.
