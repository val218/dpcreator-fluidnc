Eine frische Firmware-Installation startet bereits mit aktivem Ethernet und DHCP: Kabel einstecken und die IP herausfinden. Auf dieser Seite stellen Sie auf eine feste IP um oder wechseln von WLAN zurück.

1. config.yaml muss den Ethernet-Abschnitt enthalten

spi:
  miso_pin: gpio.13
  mosi_pin: gpio.11
  sck_pin: gpio.12

ethernet:
  cs_pin: gpio.14
  int_pin: gpio.9        # NO_PIN if INT is not wired
  rst_pin: NO_PIN
  phy_type: w5500
  phy_addr: 1
  frequency_hz: 8000000  # safe on a bus shared with the SD card

Wichtig: Wenn int_pin gesetzt ist, INT aber nicht tatsächlich angeschlossen ist, kommt der Link zwar hoch, aber es kommen keine Pakete an (DHCP schlägt fehl, Ping läuft in einen Timeout). Setzen Sie in diesem Fall int_pin: NO_PIN.

Ohne einen ethernet:-Abschnitt weicht das Board auf WLAN aus, damit es erreichbar bleibt — Ihr gespeichertes Netzwerk oder sein eigener Access Point FluidNC unter http://192.168.0.1.

2. DHCP oder feste IP wählen

Senden Sie diese Befehle über USB (serielle Konsole), eine Zeile nach der anderen.

Automatisch (DHCP):

$network/type=Ethernet
$Ethernet/IPMode=DHCP
$bye

Feste IP (empfohlen — verwenden Sie eine freie Adresse in Ihrem eigenen Netzwerk):

$network/type=Ethernet
$Ethernet/IPMode=Static
$Ethernet/IP=192.168.10.50
$Ethernet/Netmask=255.255.255.0
$Ethernet/Gateway=192.168.10.1
$bye

Danach ist WLAN aus. Zum Zurückwechseln: $network/type=WiFi, dann $bye über USB.

3. Prüfen

Nach dem Neustart sollten $Ethernet/Status oder $Startup/Show Ethernet link up und Ethernet IP is … melden. Dann die IP vom PC aus mit ping prüfen und http://<ip> oder http://fluidnc.local öffnen.

4. gSender über Ethernet

  1. Öffnen Sie in gSender Config → Ethernet.
  2. Geben Sie die IP des Boards und Port 23 (oder Ihren $Telnet/Port) ein und klicken Sie auf Apply Settings.
  3. Wählen Sie im Verbindungsmenü den Eintrag Ethernet, keinen COM-Port.

Verwenden Sie nicht den Remote Mode von gSender — der ist für die eigene Adresse des PCs gedacht und führt zu „Remote mode has been disabled“.

Nützliche Befehle

$Ethernet/StatusLink, IP, Maske, Gateway, MAC
$Ethernet/InitW5500 von Hand starten (Test)
$network/typeWiFi oder Ethernet
$Telnet/PortPort, mit dem sich gSender verbindet (Standard 23)
