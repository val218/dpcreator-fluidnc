Die Seite Flash Firmware installiert den neuesten Build direkt aus Ihrem Browser. Sie bietet immer die aktuellste Version an, automatisch aus dem Quellcode gebaut.

Was Sie brauchen

  • Chrome oder Edge auf einem Desktop-Computer. Firefox und Safari unterstützen Web Serial nicht.
  • Ein USB-Datenkabel. Reine Ladekabel erscheinen nicht als Port.

Schritte

  1. Controller: Konfiguration sichern. Laden Sie zuerst config.yaml aus dem Dateimanager der WebUI herunter. Das vollständige Image ersetzt sie durch die dpCREATOR-Beispielkonfiguration. (Das Handbediengerät behält seine Einstellungen.)
  2. Melden Sie sich bei Ihrem dpcreator.eu-Konto an. Schließen Sie das Board an, das Sie flashen möchten — Controller oder Handbediengerät, jeweils nur eines. Beim Handbediengerät stecken Sie zuerst das Controller-Kabel ab.
  3. Öffnen Sie Flash Firmware und wählen Sie den Reiter Controller oder Pendant.
  4. Controller: Klicken Sie auf Flash via browser, dann auf Connect & flash firmware, wählen Sie den seriellen Port und klicken Sie auf Install. Warten Sie auf Installation complete, starten Sie das Board neu, laden Sie Ihre config.yaml wieder hoch und starten Sie mit $bye neu. Wenn Sie die dpCREATOR WebUI verwenden, installieren Sie sie erneut über den Reiter WebUI: Das vollständige Image stellt die Standard-FluidNC-Seite wieder her, und eine Neuinstallation verbraucht kein Board.
  5. Handbediengerät: Klicken Sie auf Connect and install und wählen Sie den seriellen Port. Die Seite liest die Chip-ID des Handbediengeräts, registriert sie beim ersten Mal mit Ihrer Lizenz und installiert das neueste SmartTabUI mit seiner Lizenz. Wenn Done erscheint, startet das Handbediengerät von selbst neu. Siehe SmartTabUI installieren, aktualisieren und registrieren.
  6. Während des Flashens nicht abstecken.
