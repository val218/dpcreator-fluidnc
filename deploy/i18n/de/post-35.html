dpCREATOR Studio kann auch auf Ihrem Controller liegen, neben der WebUI. Es öffnet sich dann unter der eigenen Adresse der Maschine, funktioniert ohne Internet und sendet den G-Code direkt auf die SD-Karte. Die Installation ist mit einem dpcreator.eu-Konto kostenlos und dauert über USB etwa eine Minute. Sie funktioniert auf jedem FluidNC-4.x-Controller; mit der dpCREATOR-Firmware erhalten Sie zusätzlich die Studio-Taste in der WebUI und Jobs, die bereits vorbereitet ankommen.

Voraussetzungen: FluidNC 4.0 oder neuer auf dem Controller – Standard-FluidNC oder die kostenlose dpCREATOR-Firmware – mit etwa 500 KB freiem Flash-Speicher (der Installer prüft das), ein USB-Kabel und Chrome oder Edge auf einem Computer. Um Studio ohne Installation zu nutzen, öffnen Sie stattdessen dpcreator.eu/studio (so funktioniert Studio).

Installieren

  1. Melden Sie sich bei Ihrem dpcreator.eu-Konto an (kostenlos erstellbar).
  2. Öffnen Sie Flash Firmware, Reiter Studio, Karte Install Studio on your controller.
  3. Verbinden Sie den Controller per USB-Kabel mit dem Computer. Die Maschine muss im Zustand Idle (oder Alarm) sein, nicht mitten in einem Job. Schließen Sie alle anderen Programme, die ihren seriellen Port nutzen.
  4. Klicken Sie auf Install Studio on my controller und wählen Sie den Port des Controllers.
  5. Warten Sie auf Done. Der Controller startet nicht neu, und Ihre Einstellungen, die WebUI und die Dateien auf der SD-Karte bleiben unberührt.

Öffnen

  • dpCREATOR-Firmware: http://<your board>/studio.html, zum Beispiel http://fluidnc.local/studio.html, oder klicken Sie oben rechts in der dpCREATOR WebUI auf Studio.
  • Standard-FluidNC 4.x: http://<your board>/flash/studio.html, zum Beispiel http://192.168.1.50/flash/studio.html. Legen Sie ein Lesezeichen an.

Einen Job an die Maschine senden

  1. Erstellen Sie Ihr Design und drücken Sie Make g-code. Wenn Studio vom Controller aus geöffnet wurde, kennt es die Adresse der Maschine bereits (bei anderen Kopien tragen Sie sie in Setup ein).
  2. Drücken Sie Send. Die Datei landet im Hauptverzeichnis der SD-Karte und wird sofort vorbereitet (Prepare): Jede geöffnete dpCREATOR WebUI zeigt ihre Vorschau mit einer Leiste Run / Cancel, und das SmartTabUI-Handbediengerät zeigt sie ebenfalls. Noch bewegt sich nichts.
  3. Setzen Sie den Werkstück-Nullpunkt und drücken Sie dann Run in der WebUI oder am Handbediengerät. Keine WebUI geöffnet? Die blaue Taste WebUI oben rechts in Studio öffnet sie, mit dem Job startbereit. Ist die WebUI bereits in einem anderen Tab geöffnet, wechselt sie zu diesem Tab, statt einen neuen zu öffnen; die Studio-Taste der WebUI macht dasselbe in der Gegenrichtung.

Auf einem Controller mit Standard-FluidNC wird die Datei auf die SD-Karte gesendet, aber nicht vorbereitet (dafür ist die dpCREATOR-Firmware nötig): Starten Sie sie aus der SD-Kartenliste der WebUI.

Aktualisieren und entfernen

  • Aktualisieren: Installieren Sie erneut über die Seite Flash Firmware. Die neue Kopie ersetzt die alte. Ihre Designs bleiben erhalten: Sie werden in Ihrem Browser gespeichert, nicht auf dem Controller.
  • Entfernen: Löschen Sie studio.html.gz aus den Flash-Dateien des Controllers (Classic UI → flash files) oder senden Sie $LocalFS/Delete=/localfs/studio.html.gz in der Konsole.
  • Das Flashen der vollständigen Controller-Firmware (Merged Image) löscht die Flash-Dateien: Installieren Sie Studio danach erneut, wie bei der WebUI.

Designs in der Controller-Kopie

Browser speichern Daten pro Adresse, daher sind Designs aus der Controller-Kopie getrennt von denen auf dpcreator.eu, und eine Änderung der Board-Adresse (zum Beispiel von fluidnc.local auf die IP) zeigt eine andere Liste. Verwenden Sie Save (Projektdatei) und Open, um ein Design zu übertragen.

Wenn es nicht funktioniert

Needs Chrome or Edge on a computerWeb Serial ist in diesem Browser nicht verfügbar. Verwenden Sie Chrome oder Edge unter Windows, macOS oder Linux.
The controller does not answerPrüfen Sie das Kabel (ein Datenkabel) und den Port. Schließen Sie serielle Monitore, andere per USB verbundene WebUI-Tabs oder Programme wie LaserGRBL oder UGS.
The machine is Run / Hold / Jog …Warten Sie, bis der Job endet, oder stoppen Sie ihn und versuchen Sie es erneut.
needs FluidNC 4.0 or newerAuf dem Controller läuft FluidNC 3.x oder älter. Aktualisieren Sie ihn (die kostenlose dpCREATOR-Firmware oder Standard-FluidNC 4.x) oder verwenden Sie Studio auf dpcreator.eu.
Not enough room in the controller's flashLöschen Sie ungenutzte Dateien aus dem Flash (Classic UI → flash files) oder verwenden Sie Studio auf dpcreator.eu.
Der Browser lädt studio.html herunter, statt es zu öffnenDas tun Standard-FluidNC und ältere dpCREATOR-Builds. Öffnen Sie stattdessen /flash/studio.html oder aktualisieren Sie auf die neueste dpCREATOR-Firmware.
Too many installs in the last hourWarten Sie eine Stunde und versuchen Sie es erneut.
Send meldet, dass der Browser die Verbindung blockiert hatSie verwenden die https-Kopie auf dpcreator.eu. Öffnen Sie die Kopie auf dem Controller (http) oder verwenden Sie Download .nc.

Fragen

Nutzen Sie die Seite Support (zuerst anmelden). Nennen Sie uns den Studio-Build (die Taste i in Studio), Ihren Controller und dessen Firmware-Version, und kopieren Sie den Text unter Details auf der Installationskarte, falls die Installation fehlgeschlagen ist.
