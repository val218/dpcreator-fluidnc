Das Board gibt seine SD-Karte in Ihrem Netzwerk unter http://<board-ip>/sd frei. Binden Sie sie einmal ein und kopieren Sie G-Code darauf wie auf einen USB-Stick. Vorschauen für das Handbediengerät (.viz) werden für jede kopierte G-Code-Datei automatisch erstellt.

Windows: der einfache Weg

  1. Klicken Sie im Bereich Files der WebUI auf PC drive. Es wird ein Einrichtungsskript heruntergeladen, in dem die IP Ihres Boards bereits eingetragen ist.
  2. Doppelklicken Sie darauf (nicht „Als Administrator ausführen“ verwenden). Wenn Windows warnt, klicken Sie auf Weitere Informationen → Trotzdem ausführen.
  3. Bestätigen Sie die einzige Administrator-Abfrage mit Ja. Die SD-Karte erscheint als Laufwerk S: mit dem Namen dpCREATOR SD und wird bei jeder Anmeldung neu verbunden.

Führen Sie das Skript erneut aus, wenn sich die IP des Boards ändert. Um alles zu entfernen: dpcreator-sd-drive.cmd remove.

macOS und Linux

  • macOS: Finder → Gehe zu → Mit Server verbinden → http://<board-ip>/sd
  • Linux: Ihr Dateimanager mit dav://<board-ip>/sd oder davfs2

Tipps

  • Geben Sie dem Board eine feste IP, damit das Laufwerk auch nach einem Neustart funktioniert.
  • Die Eingabe von \\<board-ip> im Explorer führt zu einem Fehler — das Board hat keine Windows-Dateifreigabe (SMB). Verwenden Sie das Laufwerk S:.
  • Kopieren Sie keine großen Dateien, während ein Job von der SD-Karte läuft; der Job hat Vorrang.
  • Lassen Sie die .viz-Dateien neben Ihrem G-Code liegen — das Handbediengerät verwendet sie.
