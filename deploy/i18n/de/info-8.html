dpCREATOR Controller-Firmware

Kostenlos ESP32-S3 oder ESP32 WROOM-32 build 5b069b62 · 2026-10-17

FluidNC 4.1.1 mit W5500-Ethernet, der neueste Build, automatisch aktualisiert. Beim Flashen wird ein vollständiges Image geschrieben, das config.yaml ersetzt. Die folgenden Schritte erhalten Ihre Maschinenkonfiguration: Sie wird zuerst geprüft und nach dem Flashen zurückgeschrieben.

ESP32-S3-Platinen brauchen ein Modul mit 8 MB PSRAM (N8R8, N16R8 oder N32R8V). ESP32-WROOM-32-Platinen erhalten einen eigenen Build; ihre Apps laufen von der SD-Karte. Platine prüfen

So funktioniert es
  1. Verwenden Sie Chrome oder Edge auf einem Computer.
  2. Wählen Sie Ihre Maschinenkonfiguration: Ihre config.yaml, den Builder oder die auf der Platine.
  3. Verbinden Sie den Controller per USB und flashen Sie.
  4. Die Seite schreibt config.yaml zurück, startet die Platine neu und prüft ihr Boot-Log.
  5. Die angehakten Apps (WebUI, Studio, Motion) werden direkt danach installiert.
  6. Führen Sie die Prüfungen für den ersten Lauf an der Maschine durch.

Port nicht aufgeführt? Halten Sie BOOT gedrückt, während Sie das USB-Kabel einstecken.

Sie brauchen eine Konfiguration für eine neue Maschine? Verwenden Sie den Machine Builder.

Die Platinen-Tools brauchen Chrome oder Edge auf einem Computer (Web Serial). Auf Smartphones, Tablets, Firefox oder Safari funktionieren sie nicht.


    

      Anforderungen an die Platine. Diese Firmware braucht einen ESP32‑S3 mit 8 MB Octal-PSRAM: ein Modul ESP32‑S3‑WROOM‑1 N8R8, N16R8 oder N32R8V (die Teilenummer auf dem Metallschirm des Moduls endet auf R8). Module mit 2 MB PSRAM (N8R2, N16R2) oder ohne PSRAM (N4, N8, N16) werden nicht unterstützt: Ihnen geht während der Jobs der Speicher aus, und sie starten neu. Klassische ESP32-Platinen (ESP32‑WROOM‑32) werden von dieser Firmware nicht unterstützt. Verbinden Sie eine Platine, und die Tools oben zeigen Ihnen, was sie hat.
    

  
















  

    
    
Firmware flashen

    
Installiert Firmware per USB auf Ihrer Platine — keine Software nötig

    

      
1

      
Verbinden Sie Ihre Controller-Platine per USB-Kabel mit diesem Computer.

    

    

      
2

      
Verwenden Sie Chrome oder Edge — Firefox unterstützt Web Serial nicht.

    

    

      
3

      
Klicken Sie unten, wählen Sie Ihren COM-Port, und der Installer erledigt alles automatisch.

    

    

    

      Tipp: Wenn Ihre Platine nicht aufgeführt ist, halten Sie beim Einstecken des USB-Kabels die BOOT-Taste gedrückt, um in den Bootloader-Modus zu wechseln.
    

  







  

    
    
WebUI auf den ESP hochladen

    
Die .gz-Datei wird aus dem internen Dateisystem des ESP (LittleFS) ausgeliefert

    

      
1

      
Laden Sie die WebUI-Datei aus dem Firmware-Release herunter.

    

    

      
2

      
Schalten Sie Ihren Controller ein und verbinden Sie ihn mit Ihrem WLAN oder verbinden Sie sich direkt mit seinem Access Point.

    

    

      
3

      
Öffnen Sie die Weboberfläche von FluidNC: http://<controller-ip>

    

    

      
4

      
Gehen Sie zu Files, klicken Sie auf Upload und wählen Sie die Datei. Der Controller startet automatisch neu.

    

    

      
5

      
Aktualisieren Sie Ihren Browser — die neue WebUI ist jetzt aktiv.

    

    

      Hilfe nötig? Ausführliche Einrichtungsanleitungen finden Sie in der FluidNC-Dokumentation.
