Plate koplieto savu SD karti jūsu tīklā adresē http://<board-ip>/sd. Pievienojiet to vienreiz un kopējiet G-kodu uz tās kā uz USB zibatmiņu. Pults priekšskatījumi (.viz) tiek izveidoti automātiski katram nokopētajam G-koda failam.

Windows: vienkāršākais veids

  1. WebUI panelī Files noklikšķiniet PC drive. Tiek lejupielādēts iestatīšanas skripts ar jau ierakstītu jūsu plates IP adresi.
  2. Veiciet uz tā dubultklikšķi (neizmantojiet "Run as administrator"). Ja Windows brīdina, noklikšķiniet More info → Run anyway.
  3. Vienīgajā administratora pieprasījumā atbildiet Yes. SD karte parādās kā disks S: ar nosaukumu dpCREATOR SD un pievienojas no jauna pie katras pieteikšanās.

Ja plates IP adrese mainās, palaidiet skriptu vēlreiz. Lai visu noņemtu: dpcreator-sd-drive.cmd remove.

macOS un Linux

  • macOS: Finder → Go → Connect to Server → http://<board-ip>/sd
  • Linux: jūsu failu pārvaldnieks ar dav://<board-ip>/sd vai davfs2

Padomi

  • Piešķiriet platei fiksētu IP adresi, lai disks darbotos arī pēc pārstartēšanas.
  • Ierakstot \\<board-ip> Explorer logā, rodas kļūda — platei nav Windows failu koplietošanas (SMB). Izmantojiet disku S:.
  • Nekopējiet lielus failus, kamēr no SD kartes izpildās darbs; darbam ir prioritāte.
  • Atstājiet .viz failus blakus savam G-kodam — pults tos izmanto.
