Jauna programmaparatūras instalācija jau startē ar ieslēgtu Ethernet un DHCP: iespraudiet kabeli un atrodiet IP adresi. Šī lapa noderēs, lai pārietu uz fiksētu IP adresi vai atgrieztos no Wi-Fi.

1. config.yaml jābūt Ethernet sadaļai

spi:
  miso_pin: gpio.13
  mosi_pin: gpio.11
  sck_pin: gpio.12

ethernet:
  cs_pin: gpio.14
  int_pin: gpio.9        # NO_PIN if INT is not wired
  rst_pin: NO_PIN
  phy_type: w5500
  phy_addr: 1
  frequency_hz: 8000000  # safe on a bus shared with the SD card

Svarīgi: ja int_pin ir iestatīts, bet INT patiesībā nav pieslēgts, savienojums izveidojas, taču neviena pakete nepienāk (DHCP neizdodas, ping beidzas ar noildzi). Tādā gadījumā iestatiet int_pin: NO_PIN.

Bez sadaļas ethernet: plate pārslēdzas uz Wi-Fi, lai paliktu sasniedzama — jūsu saglabātajā tīklā vai savā FluidNC piekļuves punktā adresē http://192.168.0.1.

2. Izvēlieties DHCP vai fiksētu IP

Nosūtiet šīs komandas caur USB (seriālā konsole) pa vienai rindai.

Automātiski (DHCP):

$network/type=Ethernet
$Ethernet/IPMode=DHCP
$bye

Fiksēta IP (ieteicams — izmantojiet brīvu adresi savā tīklā):

$network/type=Ethernet
$Ethernet/IPMode=Static
$Ethernet/IP=192.168.10.50
$Ethernet/Netmask=255.255.255.0
$Ethernet/Gateway=192.168.10.1
$bye

Pēc tam Wi-Fi ir izslēgts. Lai atgrieztos: caur USB $network/type=WiFi un tad $bye.

3. Pārbaudiet

Pēc pārstartēšanas $Ethernet/Status vai $Startup/Show jāparāda Ethernet link up un Ethernet IP is …. Tad no datora izpildiet ping uz šo IP un atveriet http://<ip> vai http://fluidnc.local.

4. gSender caur Ethernet

  1. gSender atveriet Config → Ethernet.
  2. Ievadiet plates IP adresi un portu 23 (vai savu $Telnet/Port), noklikšķiniet Apply Settings.
  3. Savienojuma izvēlnē izvēlieties ierakstu Ethernet, nevis COM portu.

Neizmantojiet gSender režīmu Remote Mode — tas paredzēts paša datora adresei un dod kļūdu "Remote mode has been disabled".

Noderīgas komandas

$Ethernet/StatusSavienojums, IP, maska, vārteja, MAC
$Ethernet/InitPalaist W5500 manuāli (testam)
$network/typeWiFi vai Ethernet
$Telnet/PortPorts, kuram pieslēdzas gSender (pēc noklusējuma 23)
