dpCREATOR Studio var atrasties arī jūsu kontrolierī, blakus WebUI. Tad tas atveras no pašas mašīnas adreses, darbojas bez interneta un sūta G-kodu tieši uz SD karti. Instalēšana ar dpcreator.eu kontu ir bez maksas un caur USB aizņem apmēram minūti. Tā darbojas ar jebkuru FluidNC 4.x kontrolieri; ar dpCREATOR programmaparatūru jūs saņemat arī Studio pogu WebUI un darbus, kas pienāk jau sagatavoti.

Prasības: kontrolierī FluidNC 4.0 vai jaunāks – standarta FluidNC vai bezmaksas dpCREATOR programmaparatūra – ar aptuveni 500 KB brīvas vietas flash atmiņā (instalētājs to pārbauda), USB kabelis un Chrome vai Edge datorā. Lai izmantotu Studio bez instalēšanas, tā vietā atveriet dpcreator.eu/studio (kā darbojas Studio).

Instalēšana

  1. Piesakieties savā dpcreator.eu kontā (izveide ir bez maksas).
  2. Atveriet Flash Firmware, cilni Studio, kartīti Install Studio on your controller.
  3. Pievienojiet kontrolieri datoram ar USB kabeli. Mašīnai jābūt stāvoklī Idle (vai Alarm), nevis jāizpilda darbs. Aizveriet citas programmas, kas izmanto tās seriālo portu.
  4. Noklikšķiniet Install Studio on my controller un izvēlieties kontroliera portu.
  5. Pagaidiet, līdz parādās Done. Kontrolieris netiek pārstartēts, un jūsu iestatījumi, WebUI un faili SD kartē netiek skarti.

Atvēršana

  • dpCREATOR programmaparatūra: http://<your board>/studio.html, piemēram, http://fluidnc.local/studio.html, vai noklikšķiniet Studio dpCREATOR WebUI augšējā labajā stūrī.
  • Standarta FluidNC 4.x: http://<your board>/flash/studio.html, piemēram, http://192.168.1.50/flash/studio.html. Saglabājiet to grāmatzīmēs.

Darba nosūtīšana uz mašīnu

  1. Izveidojiet dizainu un nospiediet Make g-code. Ja Studio atvērts no kontroliera, tas jau zina mašīnas adresi (citās kopijās ievadiet to sadaļā Setup).
  2. Nospiediet Send. Fails nonāk SD kartes saknē un uzreiz tiek sagatavots: jebkurš atvērtais dpCREATOR WebUI rāda tā priekšskatījumu ar joslu Run / Cancel, un to rāda arī SmartTabUI pults. Pagaidām nekas nekustas.
  3. Iestatiet darba nulli, tad nospiediet Run WebUI vai pultī. WebUI nav atvērts? Zilā poga WebUI Studio augšējā labajā stūrī to atver ar gatavu darbu. Ja WebUI jau ir atvērts citā cilnē, tā pārslēdzas uz šo cilni, nevis atver jaunu; WebUI poga Studio dara to pašu pretējā virzienā.

Kontrolierī ar standarta FluidNC fails tiek nosūtīts uz SD karti, bet netiek sagatavots (tam vajadzīga dpCREATOR programmaparatūra): palaidiet to no WebUI SD kartes saraksta.

Atjaunināšana un noņemšana

  • Atjaunināšana: instalējiet vēlreiz no lapas Flash Firmware. Jaunā kopija aizstāj veco. Jūsu dizaini saglabājas: tie glabājas jūsu pārlūkā, nevis kontrolierī.
  • Noņemšana: izdzēsiet studio.html.gz no kontroliera flash failiem (Classic UI → flash files) vai konsolē nosūtiet $LocalFS/Delete=/localfs/studio.html.gz.
  • Ierakstot pilno kontroliera programmaparatūru (apvienoto attēlu), flash faili tiek notīrīti: pēc tam instalējiet Studio vēlreiz, tāpat kā WebUI.

Dizaini kontroliera kopijā

Pārlūki glabā datus atsevišķi katrai adresei, tāpēc kontroliera kopijā veidotie dizaini ir atsevišķi no dpcreator.eu veidotajiem, un, mainot plates adresi (piemēram, no fluidnc.local uz tās IP), redzams cits saraksts. Lai pārnestu dizainu, izmantojiet Save (projekta fails) un Open.

Ja nedarbojas

Needs Chrome or Edge on a computerŠajā pārlūkā Web Serial nav pieejams. Izmantojiet Chrome vai Edge operētājsistēmā Windows, macOS vai Linux.
The controller does not answerPārbaudiet kabeli (datu kabeli) un portu. Aizveriet seriālos monitorus, citas WebUI cilnes, kas savienotas caur USB, vai tādas programmas kā LaserGRBL vai UGS.
The machine is Run / Hold / Jog …Pagaidiet, līdz darbs beidzas, vai apturiet to, tad mēģiniet vēlreiz.
needs FluidNC 4.0 or newerKontrolierī ir FluidNC 3.x vai vecāks. Atjauniniet to (bezmaksas dpCREATOR programmaparatūra vai standarta FluidNC 4.x) vai izmantojiet Studio vietnē dpcreator.eu.
Not enough room in the controller's flashIzdzēsiet neizmantotus failus no flash atmiņas (Classic UI → flash files) vai izmantojiet Studio vietnē dpcreator.eu.
Pārlūks lejupielādē studio.html, nevis to atverTā dara standarta FluidNC un vecāki dpCREATOR būvējumi. Tā vietā atveriet /flash/studio.html vai atjauniniet uz jaunāko dpCREATOR programmaparatūru.
Too many installs in the last hourPagaidiet stundu un mēģiniet vēlreiz.
Send ziņo, ka pārlūks bloķēja savienojumuJūs izmantojat https kopiju vietnē dpcreator.eu. Atveriet kopiju kontrolierī (http) vai izmantojiet Download .nc.

Jautājumi

Izmantojiet lapu Atbalsts (vispirms piesakieties). Norādiet Studio būvējumu (poga i Studio), savu kontrolieri un tā programmaparatūras versiju, un, ja instalēšana neizdevās, nokopējiet tekstu zem Details instalēšanas kartītē.
